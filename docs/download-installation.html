SurfMeter for Mac · 0.1.1 Alpha 1

Before installing
This build is ad hoc signed and is not notarized. It is for development testing, not a certified public release. macOS may block it under Gatekeeper. Only use a build you trust. If macOS refuses to open it, see Apple's official guidance for safely opening apps. No security settings need to be disabled globally.

1. Move to Applications

Quit any older SurfMeter copy. Drag SurfMeter.app onto the Applications folder in this disk image. Eject the image, then open SurfMeter from Applications. Move it before connecting Chrome: the local bridge uses the app's installed location.

2. Follow the first-run walkthrough

The app opens a detailed activity window and a menu bar icon. A new installation shows a setup walkthrough. You can choose Set up later and reopen it from the window's sidebar.

3. Connect Google Chrome

In the walkthrough, choose Show Chrome extension folder. Open chrome://extensions in Chrome, turn on Developer mode, choose Load unpacked, and select the revealed ChromeExtension folder. Copy the extension's 32-letter ID, paste it into SurfMeter, and choose Connect Chrome. Open a normal web page and click the SurfMeter extension button to connect.

4. Choose recording and login behavior

Enable Record eligible Chrome activity only when ready. Recording starts off on a new installation. Launch at login is optional. Choose system, light, or dark appearance and open SurfMeter.

Use both views

The menu bar gives a quick Daily or Weekly summary. Its expand button opens the detailed window, with a date picker, search and website breakdowns. Click a website to filter the chart. Closing the window keeps tracking available in the menu bar; Quit SurfMeter stops the app.

What is included

The app and Chrome extension are bundled. Download users do not need Swift, Xcode, Node, npm or Python. Safari recording is not included. The app stores local hourly website totals; no account or cloud service is required. This development release has known resource-usage issues documented in the repository.
